# آپلود شهرنگار با گوشی

همه فایل‌های این پروژه عمداً در ریشه هستند تا در GitHub از طریق موبایل قابل آپلود باشند.

فایل‌های لازم:
- package.json
- server.js
- index.html
- login.html
- admin.html
- SETUP.md
- README-RENDER.md

بعد از آپلود همه فایل‌ها، Commit changes را بزن.

هشدار: هیچ DATABASE_URL، SESSION_SECRET یا SETUP_KEY را داخل GitHub قرار نده.
